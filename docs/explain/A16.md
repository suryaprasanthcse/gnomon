## Risky decisions

1. **A fix outside a module's scope (D-75).** The mid-decision chaos test showed an A14 defect: a health recovery that landed while a consumer tenant was deciding did not make the decision stale, because the footprint cited `ExternalService:<proxy id>:state` while X3.health writes `ExternalService:<remote service id>:state`. The footprint now cites both, found from the base graph.
2. **MU32's rule body lives in `gnomon/audit`.** The seeded bug is a mutation, so it is applied by the mutation code, not read from a test fixture; lint L1 is asserted to still refuse it, so the mutation fails loudly if that premise ever goes.
3. **Seeded scripts, not a hypothesis machine.** The interleaving is `random.Random(seed)` (as in A13, D-52), so a failure names a seed and a step and re-runs identically; it does not shrink.
